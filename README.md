# Crimson Eclipse — сайт гільдії

Односторінковий адаптивний сайт української гільдії **Black Desert Online (EU)**.
Зроблений як охайна альтернатива Google Sites: чиста семантична верстка, без
iframe-embedів, Comic Sans та зайвих залежностей.

Домен: **https://crimsoneclipse.pp.ua/**

## Оформлення

Усі ілюстрації взято з папки `image/` і конвертовано у WebP для швидкого
завантаження (оригінали PNG/JPG залишилися в `image/` як вихідники):

- `1.png` — повноекранний фон головного екрана;
- `a49b...png` — ілюстрація у блоці «Про гільдію»;
- `crimson_eclipse_heading.png` — заголовок блоку цінностей;
- `01–04_*.png` — чотири картки цінностей (2×2);
- `90c6...png` — банер блоку FAQ;
- `aca5...removebg-preview.png` — клікабельний Discord-банер;
- `jEMg...jpg` — фон блоку «Долучення»;
- `YYXe...jpg` — фон підвалу;
- `logo.png` — логотип гільдії: шапка, підвал, favicon та `apple-touch-icon`.

Щоб замінити зображення, покладіть нове в `image/`, конвертуйте у WebP
(наприклад, через ffmpeg) і оновіть шлях у `index.html` / `styles.css`.

## Як подивитися локально

Просто відкрийте `index.html` у браузері. Або запустіть локальний сервер:

```bash
python -m http.server 8080
```

і перейдіть на `http://localhost:8080`.

## Що покращено порівняно з прикладом

- **Семантична верстка** замість `Custom embed` з інлайн-HTML — контент індексується
  пошуковиками та читається скрінрідерами.
- **Єдина типографіка**: Cormorant Garamond для заголовків + Inter для тексту
  (замість `Comic Sans MS`).
- **SEO**: `title`, `meta description`, canonical, Open Graph, Twitter Card, JSON-LD,
  `lang="uk"`, `robots.txt`, `sitemap.xml`.
- **Доступність**: skip-link, видимий фокус, `aria-expanded` у меню, FAQ на
  нативних `<details>`/`<summary>`, підтримка `prefers-reduced-motion`.
- **Адаптивність**: мобільне меню, сітки, що перебудовуються, кнопки на всю ширину.
- **Продуктивність**: ілюстрації у WebP, `loading="lazy"` для зображень нижче першого
  екрана, preload для hero-фону, іконки — інлайн-SVG, CSS-анімації.
- **UX**: фіксована шапка, scrollspy, плавна поява блоків, кнопка «нагору»,
  явні CTA на Discord.
- **Готовність до хостингу**: `CNAME`, `404.html`, `robots.txt`, `sitemap.xml`,
  OG-зображення та `.nojekyll`.

## Що змінити під себе

- **Кольори** — змінні на початку `assets/css/styles.css` (`:root`).
- **Посилання на Discord** — замініть `https://discord.gg/Rm9Ku5MRwq` у `index.html`.
- **Тексти** — редагуються прямо в `index.html`.
- **Домен** — уже прописаний як `crimsoneclipse.pp.ua` у `CNAME`, canonical,
  Open Graph, `robots.txt` і `sitemap.xml`. Якщо домен зміниться, оновіть ці місця.

## Деплой на GitHub Pages

### 1. Завантажте файли в репозиторій

Створіть репозиторій на GitHub (наприклад, `crimson-eclipse`) і завантажте вміст
папки `OpCd` у гілку `main`. Репозиторій має бути **публічним** (на безкоштовному
плані GitHub Pages працює лише для публічних репозиторіїв).

### 2. Увімкніть GitHub Pages

1. Відкрийте репозиторій → **Settings** → **Pages**.
2. **Source**: `Deploy from a branch`.
3. **Branch**: `main`, папка `/ (root)` → **Save**.
4. У полі **Custom domain** впишіть `crimsoneclipse.pp.ua` → **Save**.
   GitHub побачить файл `CNAME` у репозиторії.

Після цього сайт уже буде доступний за службовою адресою
`https://ваш-нік.github.io/назва-репо/`, поки DNS не налаштований.

### 3. Налаштуйте DNS у nic.ua

У панелі nic.ua: **Мої домени** → `crimsoneclipse.pp.ua` → розділ
**«DNS-записи»** (може називатися «Редактор DNS-зони» або «Керування DNS»).

Спочатку **видаліть старі A/CNAME-записи** для `@` і `www`, якщо вони ведуть на
паркувальну сторінку nic.ua. Потім додайте:

**Корінь домену (`crimsoneclipse.pp.ua`):**

| Тип | Ім'я | Значення | TTL |
|---|---|---|---|
| A | `@` | `185.199.108.153` | 3600 |
| A | `@` | `185.199.109.153` | 3600 |
| A | `@` | `185.199.110.153` | 3600 |
| A | `@` | `185.199.111.153` | 3600 |

**Піддомен `www`:**

| Тип | Ім'я | Значення | TTL |
|---|---|---|---|
| CNAME | `www` | `ваш-нік.github.io` | 3600 |

За бажанням можна додати IPv6 (AAAA) для кореня:

```
2606:50c0:8000::153
2606:50c0:8001::153
2606:50c0:8002::153
2606:50c0:8003::153
```

> У nic.ua для pp.ua-доменів мають використовуватися DNS-сервери nic.ua.
> Перевірте це в розділі «DNS-сервери»: якщо там вказані зовнішні сервери,
> поверніть `ns` nic.ua, інакше записи з їхньої панелі не застосуються.

### 4. Перевірте DNS

На Windows:

```powershell
nslookup crimsoneclipse.pp.ua
nslookup www.crimsoneclipse.pp.ua
```

Для кореня мають повернутися IP `185.199.108–111.153`, для `www` — CNAME на
`ваш-нік.github.io`. Поширення DNS зазвичай займає від 15 хвилин до кількох годин
(іноді до 24 год).

Після цього в **Settings → Pages** має з'явитися позначка, що DNS перевірено.

### 5. Увімкніть HTTPS

Коли DNS запрацює, у **Settings → Pages** з'явиться чекбокс **Enforce HTTPS**.
Увімкніть його. GitHub автоматично випустить сертифікат Let's Encrypt (може зайняти
до 24 годин). Після цього сайт працюватиме за `https://crimsoneclipse.pp.ua/`.

Якщо сертифікат не з'явився довго — видаліть і знову додайте custom domain у
налаштуваннях Pages, щоб перезапустити випуск.

## Альтернатива: Netlify

Якщо не хочеться працювати з Git: зайдіть на Netlify Drop, перетягніть папку `OpCd`
у браузер і отримайте сайт за адресою `назва.netlify.app`. Потім у
**Domain management** додайте `crimsoneclipse.pp.ua` — Netlify покаже, які DNS-записи
прописати в nic.ua (зазвичай A-запис на IP Netlify для кореня і CNAME для `www`).
HTTPS там також вмикається автоматично.
